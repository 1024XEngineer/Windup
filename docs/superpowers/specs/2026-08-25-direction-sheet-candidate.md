# 四向八向方向候选帧规范

## 目标

四向和八向流程在动作生成前展示一张可整体确认的 3×3 方向候选图。用户只需选择一张候选图，确认后直接进入动作生成。

## 行为合同

- 八向在 3×3 网格中展示八个方向：上排为西北、北、东北，中排为西、空、东，下排为西南、南、东南。
- 四向使用相同网格，只展示东、西、北、南四个正方向；斜向格留空。西向继续遵循现有方向解析的镜像规则。
- 候选图由同一候选序号的真实源方向结果组成；不新增后端接口，不上传或伪造新的媒体 URL。
- 选择候选图后，客户端把该卡片内的真实源方向 URL 映射回现有 `confirmFirstFrame` 逐方向合同。
- 确认后沿现有自动推进链路直接提交完整动作生成。
- 单向流程和现有恢复、重试、导出数据结构保持不变。
