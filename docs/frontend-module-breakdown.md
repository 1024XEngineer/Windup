# Windup MS2 前端模块拆分 / Frontend Module Breakdown

## 主线 / Main Flow

```text
快速开始 ─────┐
              ├→ 运行工作流（画布）
从项目开始 ───┘     项目 → 角色/造型基准帧 → 动作 → 生成 → 审核 → 网页手感模拟质检 → 导出
```

所有模块都挂在一次运行工作流上。画布展示节点、连线、当前步骤和运行状态。

## A. 应用基座

> 为所有页面提供共用的路由、外壳、当前上下文和服务请求入口。

- 页面路由与导航
- 应用外壳
- 当前用户和当前项目入口
- 全局提示
- 统一服务请求

## B. 工作流 / Workflow

> 负责节点编排、连线、导航和运行状态；点开节点后进入 C–G 对应界面，不重复实现具体业务。

### B1. 快速开始 / Quick Start

- 输入自然语言需求
- 展示识别出的角色、动作和生成要求
- 确认后创建并进入工作流

需要请求：

- 解析自然语言需求
- 创建工作流运行

### B2. 从项目开始 / Start from Project

- 选择项目
- 选择已有角色或创建角色
- 选择已有动作或新增动作
- 确认后进入工作流

需要请求：

- 获取项目、角色和动作
- 创建工作流运行

### B3. 工作流画布 / Workflow Canvas

- 展示项目、角色/造型基准帧、动作、生成、审核、网页手感模拟质检和导出节点
- 展示节点连线和先后关系
- 上游节点确认后解锁下游节点
- 展示当前节点、已完成节点和待处理节点
- 点击节点查看和处理当前步骤

需要请求：

- 获取工作流运行状态
- 获取各节点状态（如正在生图中获取图片）
- 提交当前节点结果



## C. 项目与角色资产 / Projects & Character Assets

> 管理项目约束以及项目内的角色、造型、动作和资产。

### C1. 项目 / Projects

- 查看和选择项目
- 创建项目
- 设置项目名称、题材、美术风格和参考图
- 设置视角模式、方向数量和画布尺寸
- 在顶栏查看当前项目约束并切换项目

需要请求：

- 获取项目列表和详情
- 创建和修改项目名称

### C2. 角色、造型与基准帧 / Characters, Outfits & Base Frames

- 创建或选择角色
- 选择从零创建、上传参考图或使用已有角色
- 填写角色名称和角色身份描述
- 提交造型基准帧生成要求，实际生成进入 D 模块
- 选择和确认造型基准帧
- 默认继承当前项目的风格、视角和方向约束
- 查看角色已有动作

> 造型是角色的一套装扮，基准帧是该造型的定妆参考，后续动作均照它生成；MS2 每个角色单造型。

需要请求：

- 获取角色列表和详情
- 创建角色
- 获取和确认造型基准帧

### C3. 动作 / Actions

- 查看动作模板
- 选择一个动作模板应用到当前基准帧
- 查看动作状态

需要请求：

- 获取动作模板
- 创建动作
- 获取动作详情

### C4. 资产库 / Asset Library

- 查看当前项目的角色列表
- 查看造型基准帧、动作数量和帧数统计
- 按角色、视角和动作浏览资产
- 从动作资产进入审核台
- 为当前角色继续补充动作

需要请求：

- 获取项目资产概览
- 获取造型基准帧和动作资产

## D. 生成 / Generation

> 负责两类生成任务的确认、进度与重试：基准帧生成、动作生成。两类任务共用同一套机制（排队 / 质检 / 重试），但输入与产物不同。

### D1. 生成确认 / Generation Confirmation

- 基准帧生成：展示项目与角色信息，确认后生成候选基准帧
- 动作生成：展示已确认基准帧与动作要求，确认后生成候选帧
- 展示生成要求与预计积分消耗
- 确认并开始生成

需要请求：

- 发起生成（区分基准帧生成 / 动作生成）

### D2. 生成进度 / Generation Progress

- 展示任务状态：排队中、生成中、质检中、成功、失败
- 按任务类型展示步骤：基准帧生成 = 理解需求 → 生成基准帧 → 自动质检；动作生成 = 生成动作 → 自动质检
- 候选基准帧或候选帧逐步出现
- 任务失败时展示原因和重试入口

需要请求：

- 获取生成任务状态
- 获取候选基准帧或候选帧

### D3. 生成任务重试 / Generation Retry

- 重试失败任务
- 查看重试进度和结果

需要请求：

- 重试生成
- 获取重试任务状态

## E. 审核 / Review

> 负责动作预览、逐帧审核、自动质检结果查看和退回修复。

### E1. 审核对象与动画预览 / Review Target & Animation Preview

- 切换角色、视角和动作
- 播放与暂停
- 按 FPS 播放
- 逐帧前进、后退和查看

需要请求：

- 获取可审核的角色、视角和动作
- 获取动作帧和播放配置

### E2. 逐帧审核 / Frame-by-frame Review

- 查看帧列表
- 逐帧通过或退回
- 批量通过
- 在时间轴中区分待审、通过和退回帧
- 查看审核进度

需要请求：

- 获取帧审核状态
- 保存单帧或批量审核结果
- 恢复未完成的审核进度

### E3. 质检结果 / Quality Check Results

- 查看自动质检结论
- 查看透明背景、画布尺寸、脚底基线、主体高度、相邻帧位移和循环接缝结果
- 查看问题说明

需要请求：

- 获取自动质检结果和问题说明

### E4. 退回修复 / Return for Revision

- 选择需要修复的单帧或单段
- 填写退回要求
- 发起单帧或单段重生成
- 新帧返回后继续审核

需要请求：

- 发起单帧或单段重生成
- 获取修复任务状态
- 获取修复后的帧

## F. 手感模拟质检 / In-Browser Playability QA

> 在网页内模拟试玩角色，通过多动作按键绑定验证动作衔接与操作手感。这是浏览器里的手感模拟，不在真实游戏引擎中运行；真实引擎适配属于导出侧与后续工作。

MS2 纳入本模块：完成多动作选择、按键绑定、网页内模拟和退回审核。

### F1. 动作与按键绑定 / Action & Key Binding

- 选择多个已通过审核的动作
- 为移动、待机、跳跃、攻击等动作绑定按键
- 查看和修改当前按键映射

### F2. 网页内模拟 / In-Browser Simulation

- 在独立预览页面中试玩角色
- 通过 WASD 和绑定按键触发、组合和切换多个动作
- 展示当前触发按键和正在播放的动作
- 切换动作循环状态
- 检查动作循环、衔接、方向、锚点和实际操作手感

### F3. 质检结论 / QA Result

- 通过网页手感模拟质检
- 将问题定位回具体动作或帧
- 返回审核台继续修复

需要请求：

- 获取可参与模拟的动作及对应资源
- 获取和保存按键绑定
- 保存手感模拟质检结果

## G. 导出 / Export

> 将通过质检的动作组织为可下载、可导入目标引擎的资源包。

### G1. 导出内容 / Export Content

- 仅选择通过审核和网页手感模拟质检的动作
- 预览透明 PNG、序列帧、SpriteSheet、GIF 和 JSON metadata

### G2. 导出目标 / Export Target

- 选择导出格式
- 选择目标引擎
- 查看目标引擎的包结构和平台要求

### G3. 导出结果 / Export Result

- 查看导出进度
- 下载资源包
- 查看引擎导入步骤
- 返回项目或当前工作流

需要请求：

- 获取可导出动作
- 发起导出
- 获取导出状态和下载链接

（一键导入目标引擎通过后续的引擎侧插件实现）

## H. 账户 / Account

> 为用户提供注册、登录、会话恢复、登出和账户设置。

### H1. 登录与注册 / Sign In & Sign Up

- 邮箱密码登录
- 邮箱验证码
- 第三方账户登录
- 用户注册
- 忘记密码与重置密码

### H2. 用户会话 / User Session

- 当前用户
- 登录状态
- 自动恢复登录状态
- 未登录访问时进入登录页
- 登出

### H3. 账户设置 / Account Settings

- 个人资料
- 修改密码

需要请求：

- 登录、注册和登出
- 发送验证码和重置密码
- 发起第三方登录
- 获取当前用户
- 读取和修改账户资料

## I. 积分与计费 / Credits & Billing

> 为用户展示积分余额、生成报价、套餐购买和消费记录。

### I1. 积分余额 / Credit Balance

- 当前余额
- 可用额度
- 余额不足提醒
- 生成完成后展示本次积分消耗

### I2. 生成报价 / Generation Estimate

- 显示预计消耗
- 余额不足时拦截生成并引导购买

### I3. 套餐与记录 / Plans & Billing History

- 查看套餐
- 查看当前套餐
- 购买或订阅
- 按时间和消费类型查看消费记录

需要请求：

- 获取积分余额和生成报价
- 获取套餐并提交购买
- 获取消费记录
