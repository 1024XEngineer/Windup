# Windup 使用手册

> 适用版本：GitHub `main` 分支 `ebe26fd`（2026-08-26）
>
> 在线地址：[https://windup.xin](https://windup.xin)
>
> 本手册只描述当前 `main` 已有能力，不包含开放 PR、实验分支或规划中的功能。

Windup 是面向个人开发者和小型团队的 2D 角色动态素材工作台。你可以从文字描述或角色母版开始，生成角色、动作首帧和完整动画，在浏览器里试玩，并导出透明 PNG、Sprite Sheet、动画 JSON 与 ZIP 资源包。

## 第一次使用

### 注册账号

1. 打开 [Windup](https://windup.xin)。
2. 点击右上角的“注册”。
3. 依次填写邮箱、邀请码、密码、昵称和邮箱验证码：
   - 邀请码选填；从邀请链接进入时会自动带入，也可以修改或清空。
   - 密码长度为 8–128 位。
   - 昵称选填，最多 50 个字符，之后可以在账号页修改。
   - 邮箱验证码为 6 位，有效期为 5 分钟；重新发送前需要等待 60 秒。
4. 完成验证后，页面会自动进入工作台。

不填写邀请码时，注册赠送 300 积分；填写有效邀请码时，注册后共得 500 积分。

### 登录账号

登录支持两种方式：

- 邮箱验证码：填写邮箱，点击“发送验证码”，再输入收到的 6 位验证码。
- 密码登录：切换到“密码登录”，填写邮箱和密码。

使用邮箱验证码登录时，尚未注册的邮箱会在验证后自动创建账号，并获得 300 积分。

### 推荐的首次创作路线

第一次使用时，建议按下面的顺序操作：

```text
注册 / 登录
  → 新建项目并确定视角、朝向、尺寸和画风
  → Quick Start 描述角色
  → 确认角色母版
  → 确认各方向首帧
  → 生成完整动作
  → 保存到资产库
  → 进入预览台
  → 导出 ZIP 资产包
```

## 认识工作台

登录后，顶部导航提供四个主要入口。

| 入口 | 用途 |
| --- | --- |
| 首页 | 查看最近项目，继续已有流程，或进入创作、资产库和预览台。 |
| 项目资产 | 管理项目、角色、造型、动作和逐帧素材。 |
| 预览台 | 打开最近试玩过的角色，或从项目资产中选择其他角色。 |
| 创作 | 进入 Quick Start，用自然语言建立或继续制作流程。 |

生成任务运行期间，“创作”附近会显示任务状态入口。你可以先离开当前页面，再从顶部入口返回正在进行的创作。

## 创建和管理项目

项目是角色资产的生产边界。项目中的视角、朝向、精灵尺寸和画风会约束其下的所有角色，因此建议在第一次生成前确认这些设置。

### 新建项目

1. 在首页或“项目资产”页面点击“新建项目”。
2. 填写项目名称。名称最多 20 个字，同一账号下不能重名。
3. 选择游戏视角：
   - 横版视角
   - 俯视
   - 2.5D
4. 选择朝向：
   - 单向
   - 四向
   - 八向
5. 设置精灵尺寸：
   - 快捷尺寸为 128×128、256×256 和 512×512。
   - 也可以分别填写宽度和高度，合法范围为 32–2048 像素的整数。
6. 选择画风：
   - 像素：吸附母版像素网格，并将颜色收敛到母版色板。
   - 卡通：粗描线和平涂风格。
   - 手绘：保留笔触与纸纹。
   - 写实：使用渐变和体积光，不强调描线。
   - 不指定：不额外施加画风约束。
7. 点击“创建项目”。

从 Quick Start 的项目菜单进入新建页面时，创建完成后会返回 Quick Start，并自动选中这个项目。从 Workflow Editor 入口创建时，系统会同时创建初始工作流并打开节点画布。

### 管理已有项目

在“项目资产”页面打开项目卡片右上角的操作菜单，可以：

- 重命名项目：新名称会同步到项目中心。
- 删除项目：删除后无法恢复；项目下仍有角色时，系统会拒绝删除。

进入项目后，资产库会显示角色数量，以及每个角色的造型数和动作数。没有角色时，需要先通过 Quick Start 或 Workflow Editor 完成角色母版确认。

## 使用 Quick Start 创作

Quick Start 适合希望通过自然语言快速完成标准制作流程的用户。它和 Workflow Editor 使用同一份工作流数据，之后可以随时切换到节点画布继续处理。

### 1. 设置生成上下文

在发送第一条消息之前，可以设置：

- 项目：选择已有项目，或者保留“自动创建”。
- 角色母版：点击“添加母版”上传已有角色图片，支持浏览器可识别的图片格式。
- 画风：像素、卡通、手绘、写实或不指定。
- 生成方向：通过方向滑块选择单向、四向或八向。

选择已有项目后，画风和方向会继承项目设置，不能在 Quick Start 中单独修改。第一轮对话开始后，项目、画风和方向也会保持锁定，避免后续消息改变同一条工作流的基础约束。

### 2. 描述角色

在“创作指令”中描述角色的外形、身份、服装、气质和画面风格。例如：

```text
一名年轻的港口信使，短银发，深蓝短外套和红围巾，
全身像，轮廓清楚，适合 2D RPG 角色精灵。
```

建议把决定角色身份的特征写清楚，不要只写“一个战士”或“一个女孩”。如果提示词缺少关键条件或存在冲突，Agent 会要求补充，而不会直接开始生成。

如果上传了角色母版，输入框会改为动作描述；留空时默认生成待机动作。

### 3. 确认 Agent 提案与方向

Agent 会整理角色提示词，并给出可继续编辑的提案。你可以：

- 点击“确认并生成”，使用整理后的提案。
- 点击“填入输入框”，修改后再确认。
- 使用提案或 Agent 回复旁的复制按钮复制文字。
- 点击重新生成，要求 Agent 重新整理方案。

开始生成前，Agent 会再确认一次单向、四向或八向。选择后才会创建实际生成任务。

### 4. 选择角色母版

系统生成角色候选后，选择最符合预期的一张作为定妆母版。多方向流程会先确认同一个角色母版，再根据该母版生成方向集合，避免不同方向出现不同角色。

检查候选时重点关注：

- 发型、服装、配色和道具是否一致。
- 全身是否完整，脚部是否被裁切。
- 主体是否清晰，没有大面积背景或文字。
- 角色比例是否适合项目设定的精灵画布。

四向或八向结果会按方向集合显示。若某个源方向失败，可以只点击该方向的重试按钮，不必重新生成全部方向。

### 5. 生成动作

角色母版确认后，在底部输入框描述动作，例如：

```text
轻快向前行走，红围巾随步伐轻微摆动，双臂自然摆动。
```

系统先生成动作起始姿态。单向流程选择一张首帧；多方向流程需要确认一套方向首帧，或为各方向选择相应候选。确认后，系统继续生成完整动作帧。

动作完成后，你可以：

- 播放完整动作预览。
- 查看逐帧缩略图。
- 对像素素材执行“完美像素化”。
- 导出完整动作资产。
- 跳转到资产工作台。
- 跳转到 Play Test。
- 继续描述并新增动作。

### 6. 中断与恢复

生成过程中可以点击停止或“中断自动制作”。中断只停止当前页面的自动推进和事件订阅，不代表后端生成任务已经取消。重新打开同一条创作记录时，系统会根据已保存的任务 ID 恢复进度，不会因为刷新页面而重新创建同一个任务。

## 使用 Workflow Editor 创作

Workflow Editor 适合需要逐节点控制、局部重试和人工审核的用户。画布按依赖关系展示以下节点：

```text
角色设定
  → 角色母版
    → 动作首帧
      → 生成方式
        → 完整动画
          → 动画审核
```

一个角色可以有多条动作分支。角色设定和角色母版由所有动作共享，每条动作分支独立处理首帧、生成方式、完整动画和审核。

### 节点操作

1. 角色设定：填写或确认角色描述。
2. 角色母版：生成候选，选择一张，必要时重新生成或填写微调描述，最后点击“确认为定妆母版”。
3. 动作首帧：生成动作起始姿态，为每个需要的方向选择候选并确认。
4. 生成方式：
   - 视频裁剪：当前通用生成路线。
   - 三渲二：仅当所选造型已经有绑骨 3D 模型时可用；没有模型时入口会禁用。
5. 完整动画：填写只用于完整动画的动作描述，然后开始生成。
6. 动画审核：确认结果后点击“审核通过”，资产才进入完成状态。

节点失败时，先阅读卡片中的错误信息。多方向任务允许只重试失败方向；其他已经成功的方向会保留。重做节点时，旧任务之后返回的迟到结果不会覆盖新结果。

## 管理角色资产

### 查看角色与造型

进入“项目资产”，打开项目，再选择角色。角色详情页会显示：

- 角色母版及其方向。
- 当前造型。
- 动作名称、动作类型和帧数。
- 多方向动作的方向切换按钮。
- 完整逐帧序列。

点击动作卡片可以展开完整帧。多方向动作展开后，可以切换当前查看方向。

### 增加动作

角色已有母版时，点击“增加动作”，选择一种方式：

- Quick Start：描述动作后自动完成标准生成流程。
- Workflow Editor：进入已有角色工作流，手动控制每个节点。

新增动作会复用现有角色和造型，不会创建另一套独立角色流程。角色还没有母版时，“增加动作”不可用。

### 完美像素化

造型具有可播放动作时，角色详情页会显示“完美像素化”。它用于进一步整理像素网格与色板。处理可能需要几十秒；切换到其他动作后，旧动作尚未完成的结果不会错误套用到新动作。

## 在预览台试玩

预览台只读取已经保存且包含真实动作帧的角色造型，不会修改角色、动作或工作流。

### 打开角色

可以从以下位置进入：

- 角色详情页的“在预览台打开当前造型”。
- Quick Start 完成页的 Play Test 按钮。
- 首页按项目、角色和造型逐层选择。
- “预览台”中的最近预览记录。

只有包含可播放动作帧的造型才能进入。角色没有造型或动作时，先返回项目资产完成制作。

### 默认键位

| 功能 | 默认键位 |
| --- | --- |
| 向上移动 | `W` |
| 向下移动 | `S` |
| 向左移动 | `A` |
| 向右移动 | `D` |
| 主动作 | `Space` |
| 次动作 | 左 `Shift` |

只有行走或奔跑动作会推动角色在舞台内移动。斜向移动速度会归一化，不会比横向或纵向更快。松开移动键后，如果造型中有待机动作，角色会自动切换到待机。

### 修改键位和动作绑定

1. 点击需要修改的圆角键帽。
2. 按下目标物理键完成绑定。
3. 键位冲突时，系统会交换原有键位。
4. 按 `Escape` 取消本次修改。
5. 按 `Delete` 或 `Backspace` 清除动作键位。
6. 主动作和次动作可以从下拉菜单重新选择动作类型。
7. 点击“恢复默认”可以恢复默认键位。

键位按登录账号隔离，但只保存在当前浏览器。刷新、重新登录或切换角色后仍可读取；换浏览器、换设备、进入无痕窗口或清理浏览器数据后不会保留。它不是服务端账号同步。

如果当前帧图片加载失败，预览台会显示错误。点击“重试当前帧”重新请求真实资源，页面不会用占位图伪装成功。

## 导出游戏资产

角色详情页和完成后的 Quick Start 都提供导出入口。点击“导出资产包”后，浏览器依次检查条件、整理素材、生成图片并打包 ZIP。

导出包会根据当前完成阶段包含以下内容：

- 角色母版。
- 已确认的动作首帧。
- 逐帧透明 PNG。
- Sprite Sheet。
- 动画 `meta.json`。
- 资产契约 `schema.json`。
- 资源说明 `README.md`。
- 达到 Playtest 阶段时的 `playtest.json`。

典型目录结构如下：

```text
角色目录/
  character/master.png
  first-frames/
  frames/动作名/
  atlas/动作名.png
  meta.json
  schema.json
  README.md
  playtest.json
```

导出采用浏览器下载，不会修改服务器上的角色资产。出现以下情况时，系统会阻止导出并显示具体原因：

- 动作存在质量问题。
- 帧序号缺失或重复。
- 实际帧数与声明帧数不一致。
- 图片读取失败。
- PNG 缺少透明信息。
- 图片尺寸与统一画布不一致。

修复资产后，再点击“重新导出”。

## 管理账号、积分与邀请

点击顶部账号入口可以进入账号页。账号页包含四个区域：

### 个人资料

- 查看邮箱和验证状态。
- 修改昵称；昵称长度为 1–50 个字符。
- 查看邮箱验证时间。

### 登录安全

- 使用当前密码设置新密码。
- 新密码长度为 8–128 位。
- 修改成功后，当前会话会退出，需要重新登录。

### 积分账户

- 查看当前积分余额。
- 查看积分流水。
- 按变动方向、业务类型和时间范围筛选记录。
- 读取失败时可以重新加载。

### 邀请奖励

- 查看自己的邀请码及使用次数。
- 复制邀请码或专属邀请链接。
- 邀请链接会自动携带邀请码，好友注册时无需手工输入。
- 邀请成功后双方各得 200 积分；每天前 3 次成功邀请可以获得奖励。

邀请码是稳定账号信息，页面不提供主动更换入口，也不支持注册完成后补填邀请码。

## 任务恢复与常见问题

### 刷新页面后任务还在吗？

生成任务创建后，任务 ID 会写入工作流。刷新或重新打开同一条 Quick Start / Workflow Editor 记录时，系统会恢复已有任务并查询最新状态，而不是重新计费创建任务。

### 页面提示“执行记录版本冲突”怎么办？

这通常表示同一工作流在另一个标签页或设备中已经更新。点击“加载最新版本”，不要继续使用旧页面覆盖新结果。

### 某一个方向生成失败怎么办？

使用该方向旁的“重试”按钮。定向重试只重新提交失败的源方向，已经成功的方向会保留。

### 为什么不能进入预览台？

请检查：

- 角色是否已有造型。
- 当前造型是否至少有一个动作。
- 动作是否包含真实帧。
- 当前方向是否有对应帧。

预览台不会自动借用其他方向的素材，也不会回退到演示数据。

### 为什么不能删除项目？

项目下仍有角色时，系统会拒绝删除。先确认并处理项目资产，再执行删除。

### 为什么三渲二不可选？

三渲二要求当前造型已经存在绑骨 3D 模型。Windup 当前不在 Workflow Editor 中创建 3D 模型；没有模型时请使用视频裁剪路线。

### 为什么导出按钮没有出现或导出失败？

角色缺少母版、动作尚未完成，或资产不满足导出契约时，导出入口可能隐藏或显示“导出不可用”。按照页面给出的具体字段错误修复帧数、尺寸、透明通道或质量状态后再重试。

### 键位为什么换设备后丢失？

Playtest 键位只保存在当前浏览器，并按账号隔离，不会同步到服务器。换设备或清除浏览器数据后需要重新设置。

## 当前能力边界

以下能力尚不能当作当前在线主流程使用：

- History 页面已有模块骨架，但尚未注册产品路由和导航入口。
- Cocos Creator 原生 `.anim`、`.meta`、UUID 和一键导入插件尚未进入通用导出包；当前可导出通用 PNG、Sprite Sheet、JSON 和 ZIP。
- 三渲二只对已有绑骨 3D 模型的造型开放，当前页面不负责创建 3D 模型。
- Playtest 键位不是跨设备的账号云同步。
- 中断前端流程不等于取消后端正在执行的生成任务。

仓库中的实验代码、规划文档或开放 PR 不代表在线产品已经支持对应功能。最新状态请以 [`main`](https://github.com/1024XEngineer/Windup/tree/main) 和 [Issues](https://github.com/1024XEngineer/Windup/issues) 为准。
